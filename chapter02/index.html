    Chapter 02. 머신러닝과 딥러닝의 원리¶

    Part 1: 인공지능의 이해 | ⏱️ 학습 시간: 50분

    🎯 이 장에서 배우는 것¶

    • 머신러닝의 학습 과정을 비유를 들어 설명할 수 있다
    • 지도학습, 비지도학습, 강화학습의 차이를 구분할 수 있다
    • 인공신경망의 기본 구조와 딥러닝의 개념을 설명할 수 있다

    🚀 시작하며: "기계가 배운다"는 게 무슨 뜻일까?¶

    여러분, 어릴 때 개와 고양이를 어떻게 구별하는 법을 배웠나요?

    아마 누군가가 "이건 개야, 이건 고양이야"라고 가르쳐 주면서 수십, 수백 번 보여줬을 겁니다. 처음엔 헷갈렸겠지만, 보면 볼수록 귀 모양, 얼굴형, 울음소리 같은 차이를 자연스럽게 알게 됐겠죠. 아무도 "개의 귀는 이런 각도로 접혀있고, 고양이 눈동자는 이런 모양이야"라고 수식으로 설명해 주지 않았는데도요.

    컴퓨터도 바로 이런 방식으로 배울 수 있습니다. 이것이 머신러닝(Machine Learning)입니다.

    💡 핵심 아이디어: 규칙을 직접 프로그래밍하는 대신, 데이터를 통해 컴퓨터 스스로 규칙을 찾아내도록 한다.

    📚 핵심 개념 1: 머신러닝이란 무엇인가?¶

    🎭 비유로 시작: "시험 족보로 공부하는 학생"¶

    머신러닝은 마치 과거 시험 문제(족보)를 엄청나게 많이 풀어서 패턴을 익히는 학생과 같아요.

    전통적인 프로그래밍 방식을 생각해 봅시다. 예를 들어, 스팸 메일을 걸러내는 프로그램을 만든다면 어떻게 할까요?

    전통 방식: 

    IF 메일에 "무료" AND "클릭" AND "지금 바로" 포함 → 스팸

    처음엔 잘 작동하는 것 같죠? 그런데 스팸 발송자들이 "무료" 대신 "무☆료"라고 쓰면? 다시 규칙을 수정해야 합니다. 또 우회하면? 또 수정... 이 싸움은 끝이 없습니다.

    머신러닝 방식: 

    스팸 메일 수만 개 + 정상 메일 수만 개를 보여줌
→ 컴퓨터가 스스로 패턴을 찾아냄
→ 새로운 스팸 수법도 유사 패턴으로 걸러냄

    📖 정확한 정의¶

    머신러닝(Machine Learning)이란, 컴퓨터가 명시적으로 프로그래밍되지 않은 상태에서 데이터로부터 스스로 학습하여 성능을 향상시키는 알고리즘과 기술의 총칭입니다. — Arthur Samuel, 1959

    쉽게 말하면: "경험을 통해 스스로 나아지는 컴퓨터 프로그램"

    🔄 머신러닝의 학습 과정¶

    머신러닝이 배우는 과정은 크게 4단계로 이루어집니다.

    flowchart LR A[📊 데이터 수집] --> B[🧠 모델 학습] B --> C[📏 성능 평가] C -->|개선 필요| B C -->|충분히 좋음| D[🚀 실제 사용]

    각 단계를 살펴볼까요?

    1단계: 데이터 수집 학습의 재료입니다. 사진, 텍스트, 숫자 등 다양한 형태가 될 수 있어요. "쓰레기가 들어가면 쓰레기가 나온다(Garbage In, Garbage Out)"는 말이 있을 만큼 데이터 품질이 중요합니다.

    2단계: 모델 학습 데이터를 바탕으로 패턴을 찾아가는 과정입니다. 수학적 계산을 통해 최적의 규칙을 만들어냅니다.

    3단계: 성능 평가 모델이 얼마나 잘 배웠는지 확인합니다. 학습에 쓰지 않은 새 데이터로 테스트합니다.

    4단계: 실제 사용 (배포) 충분히 학습된 모델을 실제 서비스에 적용합니다.

    📚 핵심 개념 2: 머신러닝의 세 가지 학습 유형¶

    머신러닝은 "어떻게 배우느냐"에 따라 크게 세 가지로 나뉩니다. 이것은 마치 공부 방법의 차이와 같아요.

    🏫 학습 유형 비교표¶

    학습 유형 학습 방식 정답 필요 여부 비유 대표 활용 예
    지도학습 정답이 있는 데이터로 학습 ✅ 필요 선생님이 채점해주는 공부 이메일 스팸 분류, 집값 예측
    비지도학습 정답 없이 패턴 발견 ❌ 불필요 혼자 책 읽으며 분류하기 고객 그룹 분류, 이상 탐지
    강화학습 보상/처벌로 시행착오 학습 ❌ 불필요 게임하며 고득점 전략 익히기 게임 AI, 로봇 제어

    📝 지도학습 (Supervised Learning)¶

    🎭 비유: "정답지가 있는 공부"¶

    지도학습은 마치 문제와 정답이 함께 있는 문제집으로 공부하는 것과 같아요.

    "이 사진 → 고양이", "이 사진 → 개", "이 사진 → 고양이" 이런 식으로 수천 개의 (사진, 정답) 쌍을 보여주면, 모델은 점점 사진을 보고 정답을 맞히는 능력이 생깁니다.

    핵심 개념: 분류 vs. 회귀¶

    지도학습은 정답의 형태에 따라 두 가지로 나뉩니다.

    📌 분류(Classification): 정해진 카테고리 중 하나를 선택 - 예: 이 이메일은 스팸인가요? (예/아니오) - 예: 이 사진의 동물은 무엇인가요? (개/고양이/새/...) - 예: 이 종양은 악성인가요? (양성/악성)

    📌 회귀(Regression): 연속적인 숫자값을 예측 - 예: 이 집의 가격은 얼마일까요? (3억 2천만원, 5억 7천만원...) - 예: 내일 기온은 몇 도일까요? (23.5도, 18.2도...) - 예: 이 주식은 얼마가 될까요?

    🔍 비지도학습 (Unsupervised Learning)¶

    🎭 비유: "정답 없이 스스로 분류하기"¶

    비지도학습은 마치 외국어로 된 책을 받았는데, 정답 없이 혼자 읽으면서 어떤 챕터가 비슷한 내용인지 묶어보는 것과 같아요.

    정답 레이블이 없습니다. 데이터들 사이에서 자연스럽게 존재하는 패턴과 구조를 찾아냅니다.

    대표 활용: 클러스터링(군집화)¶

    가장 많이 쓰이는 비지도학습 방법은 클러스터링입니다. 비슷한 것들끼리 자동으로 묶어줍니다.

    실생활 예시:

    • 🛍️ 마케팅: 수백만 고객을 구매 패턴으로 자동 분류 → "젊은 트렌드 추구형", "가성비 중시형", "충성 고객형" 등 그룹 발견
    • 📰 뉴스 분류: 수천 개의 뉴스 기사를 자동으로 정치/경제/스포츠/연예 등으로 분류
    • 🔒 이상 탐지: 정상적인 패턴에서 크게 벗어난 거래를 금융 사기로 탐지
    graph TB A[📊 전체 고객 데이터<br/>정답 레이블 없음] --> B[🔍 클러스터링 알고리즘] B --> C[그룹 1<br/>자주 구매, 고가 선호] B --> D[그룹 2<br/>세일 때만 구매] B --> E[그룹 3<br/>특정 카테고리만 구매]

    🎮 강화학습 (Reinforcement Learning)¶

    🎭 비유: "게임으로 배우는 AI"¶

    강화학습은 마치 아무 설명 없이 게임을 시작해서, 점수가 올라가면 그 행동을 반복하고 Game Over가 되면 그 행동을 피하면서 점점 잘하게 되는 것과 같아요.

    정답을 알려주는 선생님도, 미리 준비된 데이터도 없습니다. 오직 행동의 결과(보상)를 통해 스스로 배웁니다.

    핵심 구성 요소¶

    구성 요소 설명 게임 예시
    에이전트(Agent) 행동하는 주체 플레이어 캐릭터
    환경(Environment) 에이전트가 상호작용하는 세계 게임 화면
    상태(State) 현재 상황 현재 화면 상태
    행동(Action) 에이전트가 할 수 있는 것 점프, 이동, 공격
    보상(Reward) 행동의 결과 +점수, -목숨
    flowchart LR A[🤖 에이전트] -->|행동| B[🌍 환경] B -->|상태 + 보상| A

    강화학습의 유명한 성과들¶

    • 🎮 AlphaGo (2016): 바둑 세계 챔피언을 이긴 AI — 바둑 규칙만 알고, 수백만 번 스스로 게임하며 학습
    • 🕹️ OpenAI Five: DOTA2 프로게이머 팀을 이긴 AI
    • 🚗 자율주행: 도로 환경에서 안전 운전 전략 학습
    • 🤖 로봇 제어: 넘어지지 않고 걷는 법을 스스로 습득

    📚 핵심 개념 3: 인공신경망과 딥러닝¶

    🧠 비유로 시작: "뇌를 흉내낸 컴퓨터"¶

    인공신경망은 마치 인간의 뇌 구조를 흉내낸 수학적 모델과 같아요.

    우리 뇌에는 약 860억 개의 뉴런(신경세포)이 있고, 이들이 서로 연결되어 신호를 주고받습니다. "개" 사진을 보면 눈의 시각 정보가 → 여러 뉴런을 거쳐 → "이건 개야!"라는 인식으로 이어지죠.

    인공신경망도 비슷합니다. 인공 뉴런들이 층(layer)을 이루며 연결되어 있고, 입력 데이터가 여러 층을 통과하면서 최종 답을 만들어냅니다.

    🏗️ 인공신경망의 기본 구조¶

    인공신경망은 크게 세 종류의 층으로 구성됩니다.

    세 가지 층의 역할¶

    1️⃣ 입력층 (Input Layer) - 데이터가 들어오는 문 역할 - 이미지라면 각 픽셀의 색상값, 텍스트라면 단어 정보 등이 입력됨 - 아무런 계산 없이 데이터를 다음 층으로 전달

    2️⃣ 은닉층 (Hidden Layer) - 실제 "학습"이 일어나는 곳 - 입력받은 정보를 변환하고, 패턴을 추출함 - 여러 층이 있을수록 더 복잡한 패턴 인식 가능 - 이름이 "은닉"인 이유: 입력도, 출력도 아닌 중간 단계라서

    3️⃣ 출력층 (Output Layer) - 최종 답을 내놓는 곳 - 개/고양이 분류라면 각각의 확률을 출력 (예: 개 87%, 고양이 13%)

    ⚙️ 뉴런 하나는 어떻게 작동하나?¶

    인공 뉴런은 여러 입력을 받아 → 가중치를 곱해 더한 후 → 활성화 함수를 거쳐 출력합니다.

    가중치(Weight)의 중요성: - 각 연결에는 가중치(w) 라는 숫자가 있습니다 - 가중치가 크면 → 그 입력이 출력에 더 큰 영향 - 가중치가 작으면 → 그 입력의 영향이 작음 - 머신러닝의 학습 = 올바른 예측을 위한 적절한 가중치를 찾아가는 과정

    🎯 핵심 포인트: 학습이란 수천, 수백만 번 예측을 반복하면서 틀릴 때마다 가중치를 조금씩 조정해가는 과정입니다. 마치 악기 튜닝처럼요!

    🌊 딥러닝(Deep Learning)이란?¶

    🎭 비유: "더 깊은 생각"¶

    딥러닝은 마치 여러 전문가가 단계별로 검토하는 시스템과 같아요.

    사진 속 고양이를 알아보는 과정을 생각해봅시다: 1. 첫 번째 전문가: "선과 모서리를 봅니다" 2. 두 번째 전문가: "선들이 모여 귀, 눈, 수염 같은 부분을 봅니다" 3. 세 번째 전문가: "부분들이 모여 얼굴 전체를 봅니다" 4. 최종 판단: "이건 고양이입니다!"

    딥러닝의 "딥(Deep)"은 바로 이 여러 층(deep layers) 을 의미합니다.

    머신러닝 vs. 딥러닝 차이¶

    구분 전통 머신러닝 딥러닝
    특징 추출 사람이 직접 특징 설계 데이터에서 자동으로 특징 학습
    필요 데이터 적어도 가능 대량의 데이터 필요
    계산 자원 상대적으로 적게 필요 GPU 등 고성능 자원 필요
    해석 가능성 비교적 이해하기 쉬움 블랙박스 (이해 어려움)
    성능 (복잡한 문제) 한계가 있음 매우 높은 성능
    적합한 문제 표 형태의 정형 데이터 이미지, 음성, 텍스트 등
