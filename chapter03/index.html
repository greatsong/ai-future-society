    Chapter 03. Teachable Machine으로 이미지 분류기 만들기¶

    Part 2: AI 체험 실습

    🎯 이 장에서 배우는 것¶

    • Teachable Machine이 무엇인지 설명할 수 있다
    • 이미지 분류 프로젝트를 처음부터 끝까지 직접 만들 수 있다
    • 학습 데이터의 양과 질이 AI 성능에 미치는 영향을 설명할 수 있다
    • 모델 학습 결과를 분석하고 개선 방향을 제안할 수 있다
    • 만든 모델을 저장하고 외부에서 활용할 수 있다

    💡 왜 이걸 배우나요?¶

    "AI를 만든다"고 하면 어떤 이미지가 떠오르나요?

    아마 많은 분들이 이런 장면을 상상할 것입니다. 검은 화면에 초록색 코드가 쏟아지고, 수학 공식이 빼곡히 적힌 화이트보드가 있고, 박사학위를 가진 연구원들이 밤새 컴퓨터 앞에서 씨름하는 장면. 그런데 정말 그럴까요?

    오늘 이 챕터가 끝날 무렵, 여러분은 코드 한 줄 없이 자신만의 AI 이미지 분류기를 만들게 됩니다. 브라우저만 있으면 됩니다. 회원가입도 필요 없습니다. 무료입니다.

    그리고 이것이 단순한 장난감이 아닙니다. 실제로 개발자들이 프로토타입을 만들 때, 선생님들이 수업 시연을 할 때, 스타트업이 아이디어를 검증할 때 Teachable Machine을 사용합니다.

    더 중요한 것은, 이 과정을 통해 AI 학습의 핵심 원리를 몸으로 체험하게 된다는 점입니다. "데이터가 많아야 AI가 잘 된다"는 말을 책에서 읽는 것과, 직접 데이터를 10장 넣었을 때와 100장 넣었을 때 결과가 어떻게 달라지는지 눈으로 확인하는 것은 완전히 다른 경험입니다.

    자, 준비되셨나요? 지금부터 여러분은 AI 개발자가 됩니다. 🚀

    📚 핵심 개념¶

    개념 1: Teachable Machine이란 무엇인가?¶

    비유로 시작하기¶

    어린 시절에 플래시카드로 공부한 기억이 있으신가요? 카드 앞면에 사과 그림이 있고, 뒷면에 "apple"이라고 쓰여 있는 그것입니다. 선생님이 카드를 보여주면 "사과!"라고 외치고, 맞으면 칭찬을 받고, 틀리면 다시 보여주는 방식으로 배우죠.

    Teachable Machine은 이 플래시카드 학습 방식을 AI에게 적용한 도구입니다. 여러분이 "이것은 고양이야", "이것은 강아지야"라고 반복해서 보여주면, AI가 그 패턴을 학습해서 나중에 새로운 이미지를 보고 스스로 판단하게 됩니다.

    정확한 정의¶

    Teachable Machine은 구글(Google)이 개발한 웹 기반 머신러닝 교육 도구입니다. 2017년에 처음 출시되었고, 2019년에 훨씬 강력해진 버전 2.0이 공개되었습니다.

    • 주소: teachablemachine.withgoogle.com
    • 접근 방법: 웹 브라우저에서 바로 실행 (별도 설치 불필요)
    • 비용: 완전 무료
    • 지원 기능: 이미지 분류, 음성 인식, 자세 인식

    기술적으로는 전이 학습(Transfer Learning) 방식을 사용합니다. 구글이 수백만 장의 이미지로 미리 학습시켜 놓은 기반 모델(MobileNet) 위에, 여러분이 제공하는 새로운 데이터로 추가 학습을 시키는 방식입니다. 그래서 적은 데이터로도 꽤 좋은 결과를 얻을 수 있습니다.

    예시로 확인¶

    실제로 Teachable Machine을 활용한 사례들을 살펴볼까요?

    활용 사례 분류 클래스 목적
    마스크 착용 감지기 착용/미착용/잘못착용 방역 수칙 안내
    식물 병해 진단기 건강/탄저병/흰가루병 농업 지원
    수어 번역기 A/B/C/.../Z 의사소통 보조
    음식 칼로리 측정기 밥/면/빵/샐러드 식단 관리
    폐기물 분류기 종이/플라스틱/유리/금속 재활용 교육

    이 중 많은 사례가 비전문가인 일반인, 심지어 중고등학생들이 만든 것입니다. 지금 여러분도 비슷한 것을 만들 수 있습니다.

    개념 2: 이미지 분류(Image Classification)¶

    비유로 시작하기¶

    아침에 일어나서 냉장고를 열었습니다. 다양한 음식들이 있네요. 여러분의 뇌는 순식간에 "저건 우유, 저건 주스, 저건 밑반찬"이라고 구분합니다. 이 과정이 얼마나 걸렸나요? 아마 1초도 안 걸렸을 것입니다.

    인간의 뇌가 이렇게 빠르게 사물을 구분할 수 있는 것은 수백만 번의 경험이 쌓였기 때문입니다. 태어날 때부터 우유를 보고, 만지고, 마시면서 "우유는 이렇게 생긴 것"이라는 패턴을 뇌에 새겼죠.

    AI의 이미지 분류도 똑같습니다. 수많은 이미지를 보면서 패턴을 학습하고, 새로운 이미지를 보면 그 패턴과 비교해서 "이건 아마도 A겠다"고 판단합니다.

    정확한 정의¶

    이미지 분류(Image Classification)란 입력된 이미지가 미리 정의된 카테고리(클래스) 중 어디에 속하는지를 자동으로 판별하는 AI 작업입니다.

    핵심 구성 요소:

    • 입력(Input): 분류할 이미지
    • 클래스(Class): 분류 카테고리 (예: 고양이/강아지/새)
    • 출력(Output): 각 클래스에 속할 확률 (예: 고양이 87%, 강아지 10%, 새 3%)

    중요한 점은, AI는 항상 확률로 답을 줍니다. "고양이다!" 가 아니라 "고양이일 확률이 87%다"라고 하는 것입니다. 이 확률이 높을수록 AI가 자신 있게 판단하는 것이고, 여러 클래스의 확률이 비슷하게 나온다면 AI가 헷갈려 하는 상황입니다.

    예시로 확인¶

    이미지 분류가 실생활에서 어떻게 쓰이는지 생각해봅시다:

    스마트폰 카메라의 피사체 감지 — 카메라를 켜면 자동으로 사람 얼굴을 인식하고 박스를 그려주죠? 이것이 바로 이미지 분류(정확히는 객체 감지)입니다.

    의료 영상 분석 — 엑스레이나 MRI 사진에서 종양을 찾아내는 AI도 이미지 분류 기술을 사용합니다.

    자율주행차의 신호등 인식 — "현재 신호가 빨간불인가, 초록불인가, 노란불인가"를 실시간으로 판단합니다.

    개념 3: 학습 데이터와 AI 성능의 관계¶

    비유로 시작하기¶

    외국어를 배운다고 상상해보세요. 스페인어를 배우는 학생 A는 한 달에 교과서 한 권만 보았고, 학생 B는 같은 기간 동안 드라마, 음악, 뉴스, 소설, 회화 교재 등 다양한 스페인어 자료를 접했습니다. 1년 후, 누가 스페인어를 더 잘 할까요?

    당연히 학생 B겠죠. 그런데 단순히 양만 많은 게 전부일까요? 학생 C가 있다고 해봅시다. 학생 C는 멕시코 억양의 스페인어 드라마만 10년 동안 봤습니다. 학생 C는 카스티야 스페인어를 들으면 잘 이해하지 못할 수도 있습니다.

    이것이 바로 AI 학습 데이터의 핵심입니다. 양(Quantity)도 중요하지만, 다양성(Diversity)과 품질(Quality)도 그만큼 중요합니다.

    정확한 정의¶

    AI 모델의 성능은 크게 세 가지 요소에 의해 결정됩니다:

    1. 데이터의 양(Quantity) - 더 많은 이미지 = 더 많은 패턴 학습 = 일반적으로 더 좋은 성능 - 하지만 한계가 있음: 10장에서 100장으로 늘리면 크게 개선되지만, 10,000장에서 100,000장으로 늘리면 개선 폭이 작아짐

    2. 데이터의 다양성(Diversity) - 같은 고양이 사진이라도 다양한 각도, 조명, 배경, 품종이 포함되어야 함 - 한 가지 조건의 사진만 넣으면 AI가 그 조건에만 맞는 환경에서만 잘 작동함 (과적합, Overfitting)

    3. 데이터의 균형(Balance) - 클래스 A는 500장, 클래스 B는 10장이면 AI는 A를 잘 인식하지만 B는 제대로 못 인식함 - 각 클래스의 데이터 수가 비슷해야 균형 잡힌 모델이 만들어짐

    예시로 확인¶

    다음 표를 보면서 데이터 설계의 좋고 나쁜 예를 비교해봅시다:

    상황 데이터 설계 문제점
    마스크 감지기 마스크 착용: 20장, 미착용: 20장 ❌ 너무 적음. 오인식 많음
    마스크 감지기 마스크 착용: 500장 (정면만), 미착용: 500장 ❌ 다양성 부족. 옆모습에서 오인식
    마스크 감지기 마스크 착용: 200장 (정면/측면/조명다양), 미착용: 200장 (동일 다양성) ✅ 균형 + 다양성 확보
    가위바위보 인식기 가위: 100장, 바위: 100장, 보: 100장 ✅ 균형 잡힌 설계
    가위바위보 인식기 가위: 5장, 바위: 5장, 보: 5장 ❌ 개수는 균형이나 절대적으로 너무 적음

    개념 4: 클래스(Class)와 레이블(Label)¶

    비유로 시작하기¶

    도서관에서 책을 찾을 때를 생각해보세요. 책들이 "소설", "역사", "과학", "자기계발" 같은 섹션으로 분류되어 있죠. 이 섹션 이름들이 클래스입니다. 그리고 각 책의 등에 붙어있는 분류 스티커가 레이블입니다.

    "이 책은 소설 섹션에 가야 해" — 이렇게 책(데이터)에 소속 섹션(클래스)을 붙여주는 작업을 레이블링(Labeling) 또는 태깅(Tagging)이라고 합니다.

    정확한 정의¶

    • 클래스(Class): AI가 구분할 카테고리의 종류. Teachable Machine에서는 "클래스 이름"으로 지정합니다.
    • 레이블(Label): 각 데이터(이미지)에 붙이는 정답 태그. 어떤 클래스에 속하는지를 표시합니다.
    • 레이블링(Labeling): 데이터에 클래스 태그를 붙이는 작업. 실제 AI 개발에서 가장 많은 시간이 걸리는 작업 중 하나입니다.
    예시:
클래스: [고양이, 강아지, 새]

이미지 001.jpg → 레이블: 고양이
이미지 002.jpg → 레이블: 강아지  
이미지 003.jpg → 레이블: 고양이
이미지 004.jpg → 레이블: 새

    클래스 설계 시 주의사항¶

    좋은 클래스 설계를 위한 원칙:

    1. 클래스는 서로 명확히 구분되어야 함 - 좋은 예: 고양이 / 강아지 / 토끼 - 나쁜 예: 고양이 / 동물 (고양이도 동물이라 겹침)

    2. 클래스의 수가 적을수록 학습이 쉬움 - 2~5개 클래스: 비교적 쉽게 높은 정확도 달성 가능 - 10개 이상: 각 클래스별로 훨씬 많은 데이터 필요

    3. 클래스 이름을 명확하게 지정 - 좋은 예: "마스크_착용", "마스크_미착용" - 나쁜 예: "A", "B", "C" (나중에 뭔지 모름)

    예시로 확인¶

    이번 실습에서 우리가 만들 분류기의 클래스를 미리 생각해봅시다. 이 챕터에서는 두 가지 프로젝트를 해볼 것입니다:

    프로젝트 1 (기초): 웹캠으로 손 제스처 인식기 만들기 - 클래스 A: 주먹 쥔 손 (바위) - 클래스 B: 손바닥 펼친 손 (보) - 클래스 C: 두 손가락 V자 (가위)

    프로젝트 2 (응용): 이미지 파일로 나만의 분류기 만들기 - 각자 원하는 주제 선택 (꽃 종류 / 음식 종류 / 날씨 등)

    🔨 따라하기 실습¶

    💻 준비물: 웹캠이 달린 컴퓨터 또는 노트북, Chrome 브라우저 권장

    🔵 1단계: Teachable Machine 접속하기¶

    목표: Teachable Machine 웹사이트에 접속하고 인터페이스를 확인한다

    1. 크롬(Chrome) 브라우저를 엽니다

      💡 다른 브라우저도 되지만, Chrome에서 가장 안정적으로 작동합니다

    2. 주소창에 다음을 입력합니다: 

      teachablemachine.withgoogle.com

    3. 메인 화면이 나타나면 파란색 "시작하기(Get Started)" 버튼을 클릭합니다

    4. 새 프로젝트 선택 화면에서 "이미지 프로젝트(Image Project)"를 클릭합니다

    5. 이미지 모델 유형 선택창이 나타납니다. "표준 이미지 모델(Standard image model)"을 선택합니다

      💡 표준 vs. 임베디드: 표준은 브라우저에서 실행, 임베디드는 소형 기기(라즈베리파이 등)용입니다. 우리는 표준을 선택합니다.

    이제 Teachable Machine의 메인 작업 화면이 나타납니다! 🎉

    인터페이스 구성 이해하기¶

    작업 화면은 크게 세 영역으로 나뉩니다:

    🟣 2단계: 프로젝트 설정 및 클래스 만들기¶

    목표: 가위바위보 인식기를 위한 3개 클래스를 설정한다

    1. Class 1 이름 변경: 기본으로 "Class 1"이라고 써 있는 텍스트를 클릭합니다. 연필 아이콘(✏️)이 나타나면 클릭해서 이름을 "바위"로 변경합니다.

    2. Class 2 이름 변경: 같은 방법으로 "Class 2"를 "가위"로 변경합니다.

    3. Class 3 추가: 맨 아래 "+ 클래스 추가(Add a class)" 버튼을 클릭합니다. 새로 생긴 클래스의 이름을 "보"로 변경합니다.

    이제 세 개의 클래스가 만들어졌습니다: - 🪨 바위 - ✌️ 가위
    - 🖐️ 보

    💡 팁: 클래스 이름은 나중에도 바꿀 수 있습니다. 하지만 학습이 완료된 후에는 이름만 바뀌고 모델 내용은 바뀌지 않으니, 처음에 명확하게 설정하는 것이 좋습니다.

    🟢 3단계: 학습 데이터 수집하기¶

    목표: 각 클래스에 충분한 이미지 데이터를 수집한다

    이 단계가 가장 중요하고 시간이 많이 걸리는 단계입니다. AI 성능의 80%는 데이터 품질에서 결정됩니다!

    방법 A: 웹캠으로 직접 촬영 (권장)¶

    1. "바위" 클래스의 "웹캠(Webcam)" 버튼을 클릭합니다

    2. 처음이라면 카메라 접근 권한 요청이 뜹니다. "허용"을 클릭합니다

    3. 웹캠 화면이 활성화되면, 주먹을 쥔 손을 카메라에 보여줍니다

    4. "길게 눌러서 녹화(Hold to Record)" 버튼을 꾹 누르고 있으면 연속으로 사진이 찍힙니다

    5. 최소 50장, 권장 100장 이상 찍습니다. 이때 다음을 변경하면서 찍으세요:

    6. 손의 각도 (정면, 약간 기울임, 많이 기울임)
    7. 손의 위치 (화면 중앙, 왼쪽, 오른쪽, 위, 아래)
    8. 손과 카메라의 거리 (가까이, 멀리)
    9. 손을 쥐는 방향 (손등이
