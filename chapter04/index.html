    Chapter 04: AI 모델의 성능 개선과 활용¶

    Part 2 | AI 체험 실습 · 4차시 / 8차시 · ⏱️ 50분

    🎯 이 장에서 배우는 것¶

    • 데이터 편향이 무엇인지, 그리고 AI 모델 성능에 어떤 영향을 미치는지 설명할 수 있다
    • 모델 정확도를 개선하는 구체적인 방법을 실습을 통해 경험할 수 있다
    • 완성된 AI 모델을 웹에서 직접 활용하는 방법을 알고 적용할 수 있다

    💬 지난 시간 돌아보기

    지난 챕터에서 우리는 Teachable Machine을 이용해 첫 번째 AI 모델을 만들어 봤습니다. 카메라 앞에 손을 내밀었을 때 AI가 "가위", "바위", "보"를 맞추는 모습을 보고 신기했나요? 혹시 모델이 틀리는 경우도 있었나요? 🤔

    사실 그 오류에는 이유가 있습니다. 이번 챕터에서는 바로 그 이유를 파헤치고, 더 똑똑한 AI를 만드는 방법을 배워보겠습니다!

    📚 핵심 개념 1: 데이터 편향 (Data Bias)¶

    🎭 비유로 시작하기¶

    데이터 편향은 마치 "한쪽 눈만 가리고 세상을 판단하는 것"과 같아요.

    상상해 보세요. 어떤 사람이 평생 눈이 내리는 지역에서만 살았습니다. 그 사람에게 "비가 오면 길이 어떻게 되나요?"라고 물으면 뭐라고 할까요? "길이 하얗게 덮이죠!"라고 대답할지도 모릅니다. 비가 오는 것을 한 번도 직접 경험하지 못했으니까요.

    AI도 마찬가지입니다. AI가 학습하는 데이터가 한쪽으로 치우쳐 있으면, AI의 판단도 그쪽으로 치우치게 됩니다. 이것이 바로 데이터 편향(Data Bias) 입니다.

    📖 정확한 정의¶

    데이터 편향(Data Bias) 이란, AI를 학습시키는 훈련 데이터가 특정 상황, 특정 유형, 특정 조건에 지나치게 쏠려 있어서, 그 결과로 만들어진 AI 모델이 공정하지 않거나 부정확한 판단을 내리는 현상을 말합니다.

    쉽게 말해서: "데이터가 불균형하면, AI의 판단도 불균형해진다" 는 것입니다.

    🔍 데이터 편향의 3가지 유형¶

    🎮 실제 사례로 이해하기¶

    사례 1: 손동작 인식 AI의 편향

    지난 시간에 만든 가위바위보 AI를 생각해 보세요. 만약 모든 학습 데이터를 오른손으로만 촬영했다면 어떻게 될까요? 왼손으로 "주먹"을 내밀었을 때 AI는 이것을 제대로 인식하지 못할 수 있습니다. 이것이 표본 편향입니다.

    사례 2: 의료 AI의 편향

    실제 사례로, 피부암 진단 AI가 주로 밝은 피부톤의 사진으로 학습되었을 때, 어두운 피부톤을 가진 사람들의 피부 질환을 제대로 진단하지 못하는 문제가 발생했습니다. 이는 데이터 편향이 단순한 불편함을 넘어 심각한 사회적 문제로 이어질 수 있음을 보여줍니다.

    사례 3: 채용 AI의 편향

    한 글로벌 IT 기업이 이력서를 자동으로 심사하는 AI를 개발했습니다. 그런데 과거 합격자 데이터로 학습시켰더니, 과거에 특정 그룹이 많이 채용되었다는 이유만으로 그 그룹에게 높은 점수를 주는 현상이 나타났습니다. 결국 이 AI 시스템은 폐기되었습니다.

    📊 데이터 편향 실험: 숫자로 확인하기¶

    아래 표는 같은 AI 모델을 서로 다른 데이터로 학습시켰을 때의 차이를 보여줍니다.

    실험 조건 학습 데이터 구성 전체 정확도 A 클래스 정확도 B 클래스 정확도
    실험 1 (편향됨) A: 90장 / B: 10장 85% 96% 22%
    실험 2 (균형) A: 50장 / B: 50장 88% 89% 87%
    실험 3 (풍부+균형) A: 200장 / B: 200장 95% 96% 94%

    💡 핵심 인사이트: 실험 1을 보면 "전체 정확도는 85%로 나쁘지 않아 보이지만", B 클래스는 겨우 22%만 맞추고 있습니다! 전체 수치만 보면 편향을 놓칠 수 있습니다.

    📚 핵심 개념 2: 모델 성능 개선 전략¶

    🚗 비유로 시작하기¶

    모델 성능 개선은 마치 "운전 실력을 키우는 것"과 같아요.

    처음 운전을 배울 때는 좁은 골목에서 연습했다면, 고속도로나 빗길에서는 잘 못 할 수 있습니다. 더 다양한 상황에서 더 많이 연습하고, 잘못된 부분을 코치에게 지적받아 고쳐나가야 실력이 늘죠. AI 모델도 똑같습니다.

    📖 성능 지표 이해하기¶

    모델을 개선하려면 먼저 "무엇이 문제인지" 를 숫자로 측정해야 합니다.

    정확도(Accuracy) 란 무엇일까요?

    정확도(%) = (올바르게 분류한 수 ÷ 전체 시도 수) × 100

    예를 들어, 100번 중 87번 맞췄다면 정확도는 87% 입니다.

    하지만 정확도만으로는 부족합니다. 앞서 실험 1에서 봤듯이, 전체 정확도는 높아도 특정 클래스는 형편없을 수 있거든요. 그래서 추가로 살펴볼 지표들이 있습니다.

    지표 의미 언제 중요한가?
    정확도 (Accuracy) 전체 중 맞춘 비율 일반적인 성능 측정
    정밀도 (Precision) "맞다"고 했을 때 실제로 맞는 비율 오탐지가 문제일 때
    재현율 (Recall) 실제 맞는 것 중 찾아낸 비율 놓치면 안 될 때 (질병 진단 등)
    혼동 행렬 어떤 클래스를 어디로 잘못 분류했는지 오류 패턴 파악

    🛠️ 모델 성능을 개선하는 4가지 전략¶

    🔨 따라하기 실습: AI 모델 개선 도전!¶

    🎯 오늘의 목표: Teachable Machine에서 직접 편향된 모델을 만들고, 개선하는 과정을 경험합니다.

    🔗 접속 주소: teachablemachine.withgoogle.com

    ⏱️ 예상 소요 시간: 약 25분

    Step 1: 편향된 모델 만들기 (비교 실험의 기준점)¶

    왜 먼저 나쁜 모델을 만드냐고요? 개선 전과 후를 비교해야 얼마나 나아졌는지 알 수 있기 때문입니다. 이것을 대조 실험이라고 합니다. 과학자처럼 생각해 보세요! 🧪

    ① Teachable Machine 접속 후 "이미지 프로젝트" 선택

    새 프로젝트를 시작하면 "Class 1"과 "Class 2" 두 개의 클래스가 보입니다. 이름을 바꿔봅시다.

    클래스 이름 변경 수집할 데이터 수
    Class 1 주먹 30장 (많이)
    Class 2 보자기 5장 (적게)

    ② 편향된 데이터 수집하기

    • "주먹" 클래스: 웹캠으로 30장 촬영 (다양하게 촬영하세요)
    • "보자기" 클래스: 웹캠으로 딱 5장만 촬영 (같은 자세로 비슷하게)

    ⚠️ 주의: 이것은 일부러 나쁘게 만드는 실험입니다! 나중에 고칠 거예요.

    ③ 모델 학습 및 결과 기록

    "모델 학습" 버튼을 클릭하고, 아래 표에 결과를 기록해 두세요.

    Step 2: 문제 진단하기¶

    모델을 테스트해 보면 아마도 이런 현상을 발견할 것입니다.

    🔴 예상되는 오류 패턴: - 보자기를 내밀었는데 "주먹"이라고 인식함 - 보자기의 정확도가 매우 낮음 (0~30% 수준) - 어떤 손 모양을 내밀어도 "주먹"이라고만 함

    왜 이런 현상이 발생하나요?

    데이터가 적은 클래스("보자기")를 학습할 기회가 너무 적었기 때문입니다. AI 입장에서 "보자기"는 5번밖에 본 적 없는 낯선 것이고, "주먹"은 30번이나 본 친숙한 것입니다. 모르겠으면 아는 것을 선택하는 것이 AI에게도 자연스러운 전략입니다.

    💡 비유: 10개 중 9개가 사과이고 1개가 배인 상자에서 눈감고 꺼낼 때, 무조건 "사과!"라고 외치면 90%는 맞습니다. AI가 이런 전략을 쓰는 것입니다.

    Step 3: 데이터 개선하기¶

    이제 진짜 개선을 시작합니다! 같은 프로젝트에서 "보자기" 클래스에 데이터를 추가합니다.

    📋 개선 체크리스트:

    • 보자기 클래스에 추가 촬영 (총 25~30장이 되도록)
    • 정면에서 촬영
    • 약간 옆에서 촬영
    • 가까이서 촬영
    • 조금 멀리서 촬영

    • 배경을 바꿔서 촬영

    • 주먹 클래스도 다양하게 추가 (비슷한 수준으로)

    • 학습 재시작 버튼 클릭

    💬 팁: "홀드하여 녹화" 기능을 사용하면 다양한 각도로 움직이면서 한 번에 여러 장을 찍을 수 있습니다!

    Step 5: 웹에서 모델 활용하기¶

    이제 만든 모델을 다른 사람도 쓸 수 있도록 웹에 내보내 봅시다!

    ① 모델 내보내기

    Teachable Machine 화면 상단의 "모델 내보내기" 버튼을 클릭합니다.

    ② 내보내기 옵션 선택

    팝업 창에서 다음 옵션들이 보입니다:

    옵션 설명 추천 대상
    모델 업로드 Google 서버에 저장, URL로 공유 🌟 초보자 추천
    Tensorflow.js 웹사이트에 직접 삽입 웹 개발자
    Tensorflow Lite 스마트폰 앱에 사용 앱 개발자

    우리는 "모델 업로드" 옵션을 선택합니다.

    ③ 링크 획득 및 테스트

    "업로드" 버튼을 클릭하면 잠시 후 링크가 생성됩니다.

    예시 링크:
https://teachablemachine.withgoogle.com/models/ABC123XYZ/

    이 링크를 복사해서 친구에게 보내면, 친구도 스마트폰이나 컴퓨터에서 우리가 만든 AI를 사용할 수 있습니다! 🎉

    ④ 실제 웹페이지에서 활용 (보너스)

    🔄 모델 개선의 반복 사이클¶

    좋은 AI 모델을 만드는 것은 한 번에 끝나는 일이 아닙니다. 아래와 같은 개선 사이클을 반복하는 것이 핵심입니다.

    graph LR A[📊 데이터 수집] --> B[🤖 모델 학습] B --> C[🧪 성능 테스트] C --> D{목표 달성?} D -- 아니오 --> E[🔍 문제 분석] E --> F{원인은?} F -- 데이터 부족 --> A F -- 데이터 불균형 --> A F -- 데이터 다양성 부족 --> A D -- 예 --> G[✅ 배포 및 활용] G --> H[📡 실제 환경 모니터링] H --> C

    이 사이클은 데이터 과학자, 머신러닝 엔지니어들이 실제 업무에서도 사용하는 방식입니다. 여러분도 이미 이 방법을 직접 경험해 본 것입니다! 🎊

    ⚠️ 주의할 점¶

    ⚠️ 주의 1: "정확도 함정"에 빠지지 마세요¶

    전체 정확도가 높다고 해서 좋은 모델이 아닙니다. 앞서 실험 1에서 봤듯이, 데이터가 많은 클래스는 잘 맞추지만 데이터가 적은 클래스는 거의 못 맞추는 경우가 있습니다. 항상 각 클래스별 정확도를 개별적으로 확인하세요.

    📌 체크 포인트: "가장 낮은 클래스 정확도"가 바로 모델의 진짜 약점입니다. 가장 낮은 클래스를 먼저 개선하세요.

    ⚠️ 주의 2: 실제 환경 ≠ 학습 환경¶

    모델이 학습한 환경과 실제 사용 환경이 다르면 성능이 급격히 떨어질 수 있습니다. 이것을 분포 변화(Distribution Shift) 라고 합니다.

    상황 예시
    조명이 다를 때 밝은 교실에서 학습 → 어두운 방에서 사용
    배경이 다를 때 흰 벽 앞에서 학습 → 복잡한 배경에서 사용
    카메라 거리가 다를 때 50cm 거리에서 학습 → 2m 거리에서 사용

    해결책: 학습 데이터를 수집할 때부터 다양한 환경을 포함시키세요.

    ✅ 점검하기¶

    확인 문제 (객관식)¶

    문제 1. 다음 중 데이터 편향이 발생하는 원인으로 적절하지 않은 것은?

    ① 한쪽 클래스에만 데이터가 집중되어 있다
    ② 다양한 각도와 조명에서 데이터를 수집했다
    ③ 데이터에 잘못된 레이블(이름표)이 붙어 있다
    ④ 특정 조건에서만 데이터를 수집했다

    정답 확인 **정답: ②** 다양한 각도와 조명에서 데이터를 수집하는 것은 오히려 편향을 **줄이는** 올바른 방법입니다. 나머지 ①③④는 모두 데이터 편향을 발생시키는 원인들입니다.
